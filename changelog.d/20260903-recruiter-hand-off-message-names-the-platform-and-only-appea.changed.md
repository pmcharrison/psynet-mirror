Reworded the page shown while a participant's assignment is submitted. It used to say "Communicating with the recruiter...", which exposed PsyNet's internal term for the recruitment platform. It now says "Finalizing session..." , or "Finalizing session with Prolific..." when the recruiter names a platform through the new `platform_name` attribute (Prolific, Amazon Mechanical Turk, and Lucid Marketplace do; local and generic recruitment does not). Recruiters can override `exit_message()` for full control. The message is also revealed only after 0.7s, so the usual quarter-second hand-off no longer flashes text too briefly to read, while a slow hand-off still explains itself. Translations for the new strings need regenerating with `psynet translate` before the next release.
