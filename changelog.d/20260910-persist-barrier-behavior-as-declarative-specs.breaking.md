Barrier instances now persist versioned declarative specifications instead of complete Python objects. Custom release state must use JSON-compatible values, supported callables, classes, or persisted ORM references. Waiting pages are not restored (``waiting_logic`` is always ``None``); scalar fields such as ``content`` and ``max_wait_time``, and hold-page policy such as ``_uses_timeline_hold``, are, so release callbacks may still read them from ``barrier``.
