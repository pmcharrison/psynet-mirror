When a participant leaves or is failed, PsyNet now fails that person's unfinished trials and keeps the trials they already submitted. Completed trials are failed only if a TrialMaker performance check treats those responses as unusable (`fail_trials_on_participant_performance_check`, default True for static and dense experiments, False for chain and graph experiments). Recruiter events such as a Prolific return, abandonment, or reassignment now fail the participant (including redirecting them to `unsuccessful_end` if they are still in the experiment), fail unfinished trials, keep submitted trials, and no longer fail the participant's chain nodes. `Experiment.fail_participant` now uses that same contract instead of failing owned nodes. Closing the browser on the successful-end page without clicking Finish still counts as incomplete, so a later recruiter abandonment or return fails that participant. Use `n_participants` or `n_trials` to control recruitment quotas; do not fail submitted trials for that purpose.
