Recruiter events that end a still-eligible participant (assignment abandonment, marketplace return such as a Prolific return, or reassignment) now mark the participant as a premature exit and defer completed-trial invalidation to each TrialMaker's `fail_trials_on_premature_exit` policy, instead of unconditionally failing the participant's nodes. Incomplete trials are always failed on any participant failure. Settlement returns after an already-failed or completed participant only record the recruiter cause tag.
