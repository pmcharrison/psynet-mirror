Prolific studies now pay unsuccessful participants via screen-out completion codes by default (`prolific_pay_unsuccessful = true`): failed participants are no longer asked to return their submission for a bonus, but instead paid a fixed screen-out reward plus a top-up bonus. As a consequence, Prolific deployments must now set `prolific_screen_out_slots` explicitly, since it caps the study's worst-case automatic screen-out spend; deployment fails with an explanatory error otherwise. Set `prolific_pay_unsuccessful = false` to restore the previous return-for-bonus behavior.
