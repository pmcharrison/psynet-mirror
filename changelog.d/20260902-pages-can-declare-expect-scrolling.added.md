Added an `expect_scrolling` page attribute. It declares whether a page is expected to be taller than the browser window. PsyNet's front-end tests require a page that does not set it to fit without scrolling at a typical laptop viewport (1280×720), which catches stimuli that grow large enough to push content off screen. Long pages such as consent forms set it to `True`; the bundled consent pages already do. Passing `expect_scrolling=False` to the constructor overrides a class-level `True`. It does not change how the page behaves for participants.
