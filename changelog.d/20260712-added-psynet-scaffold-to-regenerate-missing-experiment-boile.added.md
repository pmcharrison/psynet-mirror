Added ``psynet setup`` and a ``psynet scripts`` command group (``scaffold``, ``update``, and ``prune``) for creating and maintaining experiment environments: constrained ``uv`` sync, editable/commit/existing PsyNet source choices, safe scaffolding that preserves existing ``config.txt`` and ``README.md``, prune defaults that keep tracked and divergent-untracked scaffold unless ``--include-modified`` / ``--include-tracked``, in-repo demos/tests that skip pinning and ``constraints.txt`` by default, and clear usage errors when PsyNet pinning fails (including alpha/fork remotes). ``psynet generate-constraints`` (and setup locking) runs Dallinger's standalone constraints script via ``uv run`` so thin-bootstrap installs get the same Dallinger ``dev-requirements`` lock policy without importing Dallinger or using a PsyNet Docker image. ``psynet update-scripts`` remains a deprecated alias.
