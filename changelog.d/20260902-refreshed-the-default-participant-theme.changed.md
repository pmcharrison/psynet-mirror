Refreshed the default participant theme. Page content now sits on a bounded content surface over a tinted background, prose is limited to a readable measure, the accent colour meets WCAG AA contrast, keyboard focus is visible, and animations respect `prefers-reduced-motion`. The theme now lives in a cacheable stylesheet (`/static/css/participant.css`) built from `--psynet-*` custom properties, so experiments can restyle pages by redefining tokens instead of overriding rules with `!important`; see the new Theming tutorial.
