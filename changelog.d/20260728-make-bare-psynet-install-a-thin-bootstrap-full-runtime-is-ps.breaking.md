Breaking: the bare ``psynet`` package is now a thin bootstrap install (Click, Redis/Postgres clients, and setup/scripts/services tooling). The full experiment runtime moved to the ``psynet[experiment]`` extra. Standalone workflows should ``uv pip install psynet`` then ``psynet setup`` (which pins and syncs ``psynet[experiment]``). PsyNet source checkouts should install ``.[dev,...]`` (``dev`` includes the experiment runtime). Bootstrap commands work without the runtime; heavier commands error with install guidance. CI images and related jobs install the experiment extra accordingly.
