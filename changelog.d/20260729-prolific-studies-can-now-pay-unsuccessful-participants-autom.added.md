Added automatic payment of unsuccessful (failed or errored) Prolific participants via a fixed screen-out completion code. PsyNet registers an `UNSUCCESSFUL` completion code with Prolific's `FIXED_SCREEN_OUT_PAYMENT` action; unsuccessful participants then submit normally, receive a fixed payment from Prolific (`prolific_unsuccessful_base_payment`, defaulting to `min(0.25, 80% of base_payment)`), and are topped up to their accumulated reward with a bonus (controlled by `prolific_unsuccessful_topup`, with the screen-out budget capped by `prolific_screen_out_slots`). The Prolific error page now offers such participants a submit button instead of asking them to message the experimenter. The feature can be disabled with `prolific_pay_unsuccessful = false`, in which case the previous return-for-bonus flow remains the fallback; it is also disabled automatically (with a logged warning) when the Prolific workspace rejects the screen-out completion code at study creation.
