Fatal errors on generic, HotAir, and lab recruitment skip the interactive recovery page: PsyNet commits the plan and finalizes the session on the server, then still tells the participant that an error occurred. There is no Finish or Submit control, and recruiter exit is reserved for finished and voluntary-leave sessions. Prolific and Lucid still present recovery UI and commit when the participant continues. After a successful Prolific screen-out the recovery page shows a done message, and Lucid consent rejection uses a terminate callback rather than a Complete URL. Custom recruiters that present recovery UI must override ``shows_error_recovery_page``; the mixin default skips that interactive page even if ``error_page_presentation`` declares a button.
