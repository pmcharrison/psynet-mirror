Tutorial
========

This tutorial gives a hands-on introduction to PsyNet.
It is based on the workshop materials originally developed for the
ISMIR 2025 PsyNet tutorial.

Each chapter is designed to be worked through sequentially.
You will run a demo, modify it, and gradually build up to designing
your own experiments using PsyNet's static and chain paradigms.
