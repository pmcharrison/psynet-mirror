Lab research lifecycle
======================

This section describes a generic workflow that research labs can adopt
when developing, deploying, monitoring, and archiving PsyNet
experiments. It is organized around the order in which a lab member
typically works through an experiment, from one-time setup through
recruitment and teardown.

This section complements the canonical :doc:`deployment reference
<../deploy/index>`. Use the deployment reference for detailed command
behavior and server options; use this lifecycle guide when you want a
step-by-step path through a complete lab deployment.
