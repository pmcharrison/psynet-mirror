# Activate PsyNet Virtualenv

Activate the repo-local virtual environment for this chat.

1. If `.venv-psynet/bin/activate` exists, run:
   `source .venv-psynet/bin/activate`

1. If `.venv-psynet/bin/activate` exists, run:
   `source .venv-psynet/bin/activate`

1. Verify activation with:
   `echo $VIRTUAL_ENV`

1. Use this environment for all subsequent shell, Python, `pip`, `pytest`, 
   `uv`, and `pre-commit` commands in this chat.

1. If the virtual environment is missing or activation fails, tell me and stop.
