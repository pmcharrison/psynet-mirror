This directory contains pre-rendered `.wav` stimuli for the single-chord emotion replication demo.

The files are generated by `generate_stimuli.py` into `audio_file/stimuli`.

Stimulus spec:
- 14 chord conditions (major/minor/diminished/augmented triads and dominant/minor/major sevenths with specified inversions)
- 2 timbres (piano, strings)
- total: 28 files
- mono, 22,050 Hz, 4.0 seconds each
